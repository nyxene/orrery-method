# Changelog

## 0.0.4

Force marks that read as words. A section heading ended in `{rule}`, which the
site turned into a badge and every other reader — GitHub, or a tool reading the
markdown — saw as markup. It is now `· *Rule*`, and Proven is `· *Rule, proven*`.
The site is unchanged, and so is every sentence of the corpus but the one in
Overview that shows how standing is written.

## 0.0.3

The method is text. This repository holds the documents, their site and their
licence, and nothing that installs or runs. An appendix, Application, says how a
project takes the method up and names one tool that follows it.

## 0.0.2

Links that work where GitHub renders the markdown. Cross-references in `en/` and
`ru/` name the document's file and diagrams are linked relative to it, so both
read on GitHub as they do on the site; `method.md`'s headings are `2. Roles`
rather than `2 · Roles`, whose GitHub anchor every link in the file missed. The
count is twelve documents everywhere.

## 0.0.1

First publication. The corpus in English and Russian, twelve documents each,
with the whole of it as one file for agents.
